# 🏦 Parabank Web Automation Project

Automated functional testing project for [Parabank](https://parabank.parasoft.com/parabank/index.htm), a demo online banking website. This project is built using **Selenium WebDriver**, **TestNG**, and **Allure Reporting**, designed to simulate real-world banking operations.

---

## 🔧 Tech Stack

- **Test Framework:** TestNG
- **Automation Tool:** Selenium WebDriver (Java)
- **Build Tool:** Gradle
- **Reporting Tool:** Allure Reports
- **Design Pattern:** Page Object Model (POM)

---

## ✅ Modules Covered

| Module              | Test Case Description                        |
|---------------------|----------------------------------------------|
| Registration        | Register new user, handle blank field cases  |
| Login               | Valid & Invalid login scenarios              |
| Account Overview    | View account balance                         |
| Transfer Funds      | Valid & Invalid fund transfer                |
| Bill Pay            | Valid & Invalid bill payments                |
| Profile             | Update contact information                  |
| Transaction History | Search past transactions                    |

## Project Structure
```src/
├── main/java/pages/           → Page Object files
├── test/java/tests/           → Test classes
│
testng.xml                     → Test suite config
build.gradle                   → Gradle dependencies & Allure config
allure-results/                → Raw test outputs
allure-report/                 → Final report folder
               

```
